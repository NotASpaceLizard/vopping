Grocery List — Row Density Picker

Four real, tappable candidates for how tight the list rows should be — same 10-item list rendered each way inside a fixed-height frame (240px, a rough stand-in for the visible list area on a phone), itself capped at 375px wide so it's honest about phone-width crowding even if you're viewing this on a desktop. Tap the rows in each box; checking/unchecking works for real so you can feel how forgiving each tap target is, not just look at it. The "items visible" number below each is measured live from the actual rendered rows, not estimated. Option A is vacking's current style, included only as the "too sparse" baseline to compare against — not a real option. Tell me the letter you want (or "mix of B and C", etc.) and I'll lock that as the row spec.

Revised 2026-09-04: each row now also shows the delete, up/down-reorder, and note/aisle-edit controls that will really share the row later (they were missing from the first draft you may have already seen). Delete/Up/Down/note/aisle are visual placeholders only — they don't do anything when tapped except (for the top row's Up and bottom row's Down) show disabled, matching real behavior. Only the checkbox/row-tap itself is fully live. This is what actually determines whether a given density survives once every real control lands on the row, not just how it looks with checkbox+name+aisle alone.
