exclusively on a phone, in a grocery store. This supersedes the stale top-of-file framing in

**Tech stack decision (locked, 2026-09-04):** plain HTML/CSS/JS, no framework, no build step, no
backend, persistence via `localStorage` — identical architecture to sibling project vacking

a static host; no network calls of any kind are part of this app's normal operation.
